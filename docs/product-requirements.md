# プロダクト要求定義書

## プロダクトビジョンと目的

メルカリでいいね（お気に入り）した商品をeBayに自動出品することで、日本の中古市場と海外のeBay市場の価格差を収益に変える。
手作業で行っていたリサーチ・出品作業を自動化し、個人が副業として持続可能な輸出転売ビジネスを運営できるようにする。

## ターゲットユーザー

- 日本国内でメルカリを利用しており、商品をいいねして候補として管理している個人
- eBayへの輸出転売に興味があるが、手作業の多さから継続が難しいと感じている人
- Python が動く環境（Windows/Mac/Linux）を持ち、CLIツールを使える人

## 主要な機能一覧

| # | 機能 | ステータス |
|---|---|---|
| 1 | メルカリいいね商品リストの取得 | 開発中（Step 1） |
| 2 | eBay 出品価格の計算（仕入れ価格＋送料＋手数料） | 既存実装あり（`src/analysis/profit_calculator.py`） |
| 3 | eBay での相場確認 | 既存実装あり（`src/scrapers/ebay.py`） |
| 4 | eBay への自動出品 | 未実装（将来ステップ） |
| 5 | Slack/LINE 通知 | 既存実装あり（`src/alerts/notifier.py`） |
| 6 | データ永続化（SQLite） | 既存実装あり（`src/db/`） |

## 成功の定義

- メルカリでいいねした商品が、CLIコマンド1つで自動的にリストアップされる
- 各商品のeBay出品価格（仕入れ価格＋国際送料＋メルカリ手数料＋eBay手数料）が自動計算される
- いいねした商品が全てeBayに自動出品される

## ビジネス要件

- 初期コストを最小化：有料APIではなく、ブラウザ自動化（Playwright）を活用
- メルカリ・eBayのサービス変更に対してできるだけ追従しやすい設計
- セッション情報はローカルに保存し、毎回ログイン操作を不要にする

## ユーザーストーリー

1. **いいね商品の確認**  
   「メルカリでいいねした商品を、PCのCLIで一覧表示したい」

2. **eBay出品価格の自動計算**  
   「各商品の仕入れ価格に送料・各種手数料を加えた金額をeBay出品価格として自動で計算してほしい」

3. **eBay自動出品**  
   「いいねした商品を全てeBayに自動で出品してほしい」（将来）

## 受け入れ条件（Step 1: いいね取得）

- `python -m src.main likes` を実行するとメルカリのいいね商品一覧が取得できる
- 初回はブラウザウィンドウが開き、ユーザーが手動でログインできる
- 2回目以降はセッションを再利用してログインなしで動作する
- 取得した商品は DB に保存され、`python -m src.main status` で確認できる

## 機能要件

- いいね商品: 商品ID、タイトル、価格（JPY）、コンディション、URL、サムネイル画像URLを取得
- ページネーション対応：いいね件数が多くても全件取得できる
- 重複除外：同じ商品が複数回保存されない（`source_id` によるupsert）

## 非機能要件

- レート制限：スクロール間に適切な待機時間を設ける（ページ負荷を考慮）
- セキュリティ：セッションファイル（`data/mercari_session.json`）は `.gitignore` で除外
- ポータビリティ：Windows/Mac/Linux で動作すること

# タスク要件：メルカリいいね商品リスト取得

## タスク概要

メルカリでいいねした商品の一覧を取得する機能を追加する。
これは「メルカリいいね → eBay 自動出品」パイプラインの第一ステップ。

## 背景と目的

- ユーザーはメルカリで仕入れ候補商品をいいねして管理している
- 現在の `scan` コマンドはキーワード検索のみ対応しており、いいね一覧は取得できない
- いいね商品を DB に取り込むことで、後続の出品価格計算・eBay 自動出品につなげる

## 機能要件

1. `python -m src.main likes` コマンドで実行できること
2. メルカリのいいね商品（全件）を取得できること
3. 商品情報として以下を取得すること：
   - 商品ID、タイトル、価格（円）、コンディション、URL、サムネイル画像URL
4. 取得した商品を `source_listings` テーブルに保存できること（`source="mercari_likes"`, `category="unknown"`）
5. 重複商品は upsert で処理し、エラーにならないこと
6. 初回実行時はブラウザウィンドウが開き、ユーザーが手動でログインできること
7. 2回目以降はセッションを再利用してログインなしで動作すること
8. `--no-save` オプションで DB 保存をスキップできること
9. `--limit N` オプションで取得件数を制限できること

## 非機能要件

- セッションファイル（`data/mercari_session.json`）は `.gitignore` で除外すること
- スクロール間に適切な待機を設け、サーバー負荷を考慮すること
- メルカリのサービス変更に対してできるだけ堅牢な実装にすること

## 制約

- 公式 Mercari API（ショップ向け）は使用しない
- `mercapi` ライブラリはいいね取得に非対応のため使用しない
- Playwright でブラウザを動かし、ページが内部的に呼び出す API を傍受する方式を採用
- `BaseScraper` は継承しない（キーワード検索と責務が異なるため）

## 受け入れ条件

- [ ] `python -m src.main likes --no-save` を実行するとメルカリのいいね商品一覧が出力される
- [ ] 初回実行時にブラウザが開き、手動ログイン後に自動で全件取得できる
- [ ] 2回目以降はブラウザが開かずに直接取得できる
- [ ] `python -m src.main likes --save` 後に `python -m src.main status` でリスト数が増えている
- [ ] `data/mercari_session.json` が `.gitignore` に含まれていること

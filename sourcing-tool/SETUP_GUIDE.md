# eBay売却データ分析ツール — セットアップガイド（Windows）

**所要時間**: 初回セットアップ 20〜30分、以降の実行は5分

---

## 手順1: Pythonをインストールする

Pythonはこのツールを動かすのに必要なソフトです（無料）。

1. https://www.python.org/downloads/ にアクセス
2. 黄色い **「Download Python 3.x.x」** ボタンをクリック
3. ダウンロードされた `.exe` ファイルをダブルクリックして実行
4. **超重要**: 最初の画面の一番下にある **「Add python.exe to PATH」にチェックを入れる** ← これを忘れると動きません
5. **「Install Now」** をクリック
6. 「Setup was successful」と出たら完了。閉じてOK

### 確認方法

1. `Windows + R` を押す → 「cmd」と入力してEnter（コマンドプロンプトが開く）
2. 以下を入力してEnter:
   ```
   python --version
   ```
3. `Python 3.13.2` のように表示されればOK
4. エラーが出る場合 → PCを再起動してからもう一度試す

## 手順2: ツールをダウンロードする

1. ブラウザで以下にアクセス:
   ```
   https://github.com/froger1985/froger1985
   ```
2. 緑色の **「Code」** ボタンをクリック
3. **「Download ZIP」** をクリック
4. ダウンロードフォルダに `froger1985-main.zip` が保存される
5. ZIPファイルを**右クリック** → **「すべて展開」** → **「展開」**

展開すると以下のようなフォルダ構成になります:
```
froger1985-main/
  └── sourcing-tool/
        ├── ebay_sold_analyzer.py  ← これがメインのツール
        ├── data/                   ← 結果がここに保存される
        └── ...
```

---

## 手順3: 必要なライブラリをインストールする

1. コマンドプロンプトを開く（`Windows + R` → 「cmd」→ Enter）
2. 以下をコピペしてEnter:
   ```
   pip install httpx selectolax
   ```
3. 色々とダウンロードが始まる
4. 最後に **`Successfully installed`** と出ればOK

**もし `pip が見つからない` とエラーが出たら:**
```
python -m pip install httpx selectolax
```

---

## 手順4: ツールを実行する

### まずフォルダに移動する

コマンドプロンプトで以下を入力（パスはZIPを展開した場所に合わせてください）:

```
cd %USERPROFILE%\Downloads\froger1985-main\sourcing-tool
```

**注意**: もし展開先がデスクトップなら:
```
cd %USERPROFILE%\Desktop\froger1985-main\sourcing-tool
```

### テスト実行（2〜3分）

まずはツールが正常に動くか確認します:

```
python ebay_sold_analyzer.py --keywords "parappa rapper,smart doll,anime production cel" --pages 1 --output data/quick_test.csv
```

画面に商品データが流れてきたら成功です。

### 本格実行: 自動発掘モード（30〜60分）

70個のキーワードで広く探索します。時間がかかるのでPCを開いたまま放置してください:

```
python ebay_sold_analyzer.py --discover --pages 2 --output data/full_discovery.csv
```

### 好きなキーワードで検索

自分で考えたキーワードでも検索できます:

```
python ebay_sold_analyzer.py --keywords "popee performer,tokyo mew mew,japanese vintage walkman,japanese city pop vinyl" --pages 2 --output data/my_search.csv
```

## 手順5: 結果の見方

### 画面に表示される内容

```
======================================================================
📊 Keyword: anime production cel
======================================================================
  売却数:       45件           ← 多いほど需要がある
  平均価格:     $127.50        ← eBayでの平均売却価格
  価格帯:       $15.00 〜 $890.00
  中央値:       $85.00         ← 平均より現実的な価格
  ユニークセラー: 12人          ← 売っている人の数
  日本セラー:    8人            ← 日本から発送しているセラー
  偽装疑い:      2人            ← 日本なのに別の国を表示している人
  競合レベル:    MEDIUM 🟡
```

### 見るべきポイント

| 指標 | 良い兆候 | 意味 |
|------|---------|------|
| 競合レベル | **LOW 🟢** | 日本セラーが少ない = チャンス |
| 売却数 | **20件以上** | 需要がちゃんとある |
| 平均価格 | **$30以上** | メルカリ仕入れでも利益が出る |
| 偽装疑い | **1人以上いる** | 既に日本から売ってる人がいる = 需要の証拠 |

**最高の組み合わせ**: LOW🟢 + 売却数多い + 平均価格高い

### 最後のサマリー

実行が終わると、有望順にランキングが表示されます:

```
🏆 有望なキーワード (売れているが競合が少ない):

  LOW 🟢      | sold: 45 | avg:$ 127.50 | sellers:12 (JP:8+疑2) | anime production cel
  LOW 🟢      | sold: 23 | avg:$  85.00 | sellers: 5 (JP:3+疑1) | sofubi japan
```

→ **上にあるものほど有望**

### Excelで詳しく見る

`data` フォルダに結果ファイルが保存されます:

- **`full_discovery_summary.csv`** — キーワードごとの集計。Excelで開いて並べ替えると見やすい
- **`full_discovery_items.csv`** — 売れた商品の全リスト。具体的にどんな商品が売れてるかわかる

**CSVをExcelで開く方法:**
1. ファイルをダブルクリック → Excelで開く
2. 文字化けする場合:
   - Excelで「ファイル」→「開く」→「参照」→ CSVファイルを選択
   - 「テキストファイルウィザード」が出たら「ファイルの元の形式」で **65001: Unicode (UTF-8)** を選ぶ

## 手順6: 結果をもとに利益を計算する

有望なキーワードが見つかったら:

### 1. メルカリで仕入れ価格を確認

ブラウザでメルカリを開いて、同じ商品を検索。売り切れ品の価格を見る。

### 2. ざっくり利益計算

```
利益 = eBay売却価格(円換算) - メルカリ仕入れ価格 - 送料 - 手数料

例:
  eBayで $80 で売れる → 約12,000円 (1ドル=150円)
  メルカリで 3,000円 で仕入れ
  送料(EMS): 2,500円
  eBay手数料(15%): 1,800円
  ─────────────
  利益: 12,000 - 3,000 - 2,500 - 1,800 = 4,700円 ✅
```

**利益率30%以上**（この例では約39%）なら出品候補です。

## トラブルシューティング

### 「python が見つからない」

→ 手順1でPythonインストール時に **「Add python.exe to PATH」のチェックを忘れた**
→ Pythonを再インストール（今度はチェックを入れる）→ PCを再起動

### 「403 Forbidden」エラーが出る

→ eBayがアクセスをブロックしています
→ **5〜10分待ってから再実行**
→ VPNを使っている場合は**オフにして**から再実行
→ それでもダメなら連絡ください（SerpAPI対応に切り替えます）

### 「ModuleNotFoundError: No module named 'httpx'」

→ 手順3のライブラリインストールをもう一度実行

### 途中で止まった / 中断したい

→ `Ctrl + C` を押すと中断できます。それまでの結果は保存されません。

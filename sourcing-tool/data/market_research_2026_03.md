# eBay × 日本ニッチ商品 マーケットリサーチ結果
**調査日: 2026年3月21日**

## 調査方法

この環境からeBayへの直接アクセス（スクレイピング/API）はプロキシにブロックされるため、
Web検索で間接的に市場データを収集した。実際のツール運用時はローカルPCまたはVPSから実行する必要がある。

## 有望カテゴリ一覧

### 🟢 Tier 1: 高利益率・低競合（最優先で攻めるべき）

#### 1. アニメ制作セル画・原画 (Production Cel / Genga)
- **eBay平均ROI**: 非常に高い（一点もの）
- **価格帯**: $29〜$5,000+
- **仕入れ元**: ヤフオク、メルカリ、まんだらけ
- **競合**: 専門セラーがいるが市場が大きく、商品が無限にある
- **ポイント**:
  - 日本のスタジオは制作資料の保管が杜撰 → 安く流出する
  - 海外コレクターは「本物のアニメ制作素材」に高い価値を見出す
  - セル画、原画(genga)、動画(douga)の3種類がある
  - 人気作品: セーラームーン、ドラゴンボール、ナルト、ブリーチ
  - 複製原画は以前の成功リストにもあり、実績あり

#### 2. ソフビ・怪獣ビニールフィギュア (Sofubi / Kaiju Vinyl)
- **価格帯**: $80〜$3,000+（ビンテージは特に高額）
- **利益率**: 限定品で260%以上のマークアップ事例あり
- **仕入れ元**: ワンフェス、デザフェス、メルカリ、ヤフオク
- **競合**: 海外コレクター市場が急拡大中だが、仕入れに日本在住が有利
- **ポイント**:
  - ブルマァク、ポピー、マルサンの60-70年代ビンテージは数百〜数千ドル
  - 現代のアーティストソフビも限定版は即完売→リセール2-4倍
  - 海外のソフビコレクターコミュニティが活発

#### 3. 日本限定フィギュア・グッズ (Japan Exclusive)
- **eBay平均ROI**: 441%（2024年データ）
- **価格帯**: $20〜$500+
- **仕入れ元**: メルカリ、駿河屋、まんだらけ
- **競合**: 多いが、ニッチ作品に絞れば低い
- **ポイント**:
  - 日本のサイトは海外発送しないことが多い → 地理的優位性
  - ワンピース、鬼滅の刃、ヒロアカが売上トップ
  - ただし人気作品は競合も多い → マイナー作品の限定品を狙う

### 🟡 Tier 2: 中利益率・ニッチ（前回の成功パターンに近い）

#### 4. ゲーム関連グッズ（ゲーム本体ではない）
- **価格帯**: $15〜$200+
- **仕入れ元**: メルカリ、駿河屋、ブックオフ
- **競合**: ゲーム本体は激戦、グッズは比較的少ない
- **対象例**:
  - パラッパラッパー関連グッズ（フィギュア、サントラ等）
  - ウンジャマラミー関連
  - ゲームサントラ（特にビニール盤）
  - ゲームアートブック
  - ゲームキャラクターぬいぐるみ・キーホルダー

#### 5. Smart Doll / BJD (ボールジョイントドール)
- **eBay価格帯**: $370〜$820+（廃盤モデルは更に高額）
- **定価**: 約$487（52,000円）
- **仕入れ元**: 公式サイト、メルカリ（中古）
- **競合**: 中程度
- **ポイント**:
  - 廃盤・引退モデルがプレミアム化
  - 2025年9月から米国の日本輸入品に新たな関税 → 国内中古市場に需要流入
  - ドール服・パーツ単体でも売れる

#### 6. 麻雀・花札・伝統ゲーム
- **価格帯**: $30〜$200+（ビンテージは$500+）
- **仕入れ元**: メルカリ、ヤフオク
- **競合**: 低い
- **ポイント**:
  - 麻雀は「咲-Saki-」やアニメの影響で海外でも認知度上昇
  - 任天堂の花札は海外コレクターに人気
  - AMOS等の本格麻雀牌は$200前後

### 🔵 Tier 3: 拡張候補（リサーチ次第）

#### 7. シティポップ・ビニールレコード
- シティポップブームは継続中。日本盤LPは海外で高値

#### 8. 日本の文房具
- 2025年、海外需要が急増中。万年筆、プランナー、紙製品

#### 9. 日本の調理器具
- 和包丁、南部鉄器等。精密性・耐久性・デザイン性で人気

#### 10. アイドルグッズ
- K-POPほどではないがJ-POPアイドルグッズにも需要あり

## 推奨する攻め方

### Phase 0（今）: ローカルPCでツールを実行して検証
1. eBay売却データ分析ツールをローカルPCで実行
2. 上記Tier 1カテゴリのキーワードで実際の売却価格・競合数を確認
3. メルカリで同じ商品の仕入れ価格を確認
4. 利益が出る商品を10〜20品特定

### Phase 1（1-2週間）: テスト出品
1. 特定した商品を無在庫出品
2. 売れるか・どのくらいの速度で売れるかを検証
3. 特にTier 1のセル画・原画とソフビを重点的に

### Phase 2（1ヶ月〜）: 自動化・拡大
1. 商品発掘の自動化
2. メルカリ価格監視の自動化
3. 出品数を100品まで拡大

## データソースの制約と対策

| 課題 | 対策 |
|------|------|
| この環境からeBayにアクセスできない | ローカルPCでスクリプトを実行する |
| eBayの直接スクレイピングは403になることがある | SerpApi ($50/月) または residential proxy を使う |
| eBay Finding API（売却済み検索）は2025年2月に廃止 | Browse API（出品中のみ）+ スクレイピング or SerpApi |
| メルカリはBot検出が厳しい | mercapi ライブラリ + 日本IP proxy |
